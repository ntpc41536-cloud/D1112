# 數位科技概論（上）隨堂測驗練習系統

本網站是以您資料夾中的實體測驗卷照片（`15867.jpg`、`15868.jpg`）為基礎製作的現代化互動式線上題庫與測驗平台。

- **測驗科目**：數位科技概論（上）隨堂測驗卷 第 3 回
- **章節範圍**：第 3 章 系統平台的組成架構 - 硬體
- **題數與配分**：共 25 題單選題，每題 4 分，滿分 100 分

---

## 🌟 核心功能特色

1. **三大多功能模式**：
   - 📝 **全真測驗模式 (Exam Mode)**：
     - 25 分鐘倒數計時器
     - 答題進度條與 25 題導航矩陣（即時標註：未答 / 已答 / 標記）
     - 支援「題目標記」功能，方便作答後回頭檢查
     - 交卷防呆提示（未答題數警示）
     - 完整成績報告單（滿分評級、作答耗時、答對/答錯題數分析、高分彩帶慶祝特效）
     - 交卷後自動轉為「詳解檢視」模式（綠色顯示正解、紅色標記錯選）
   - ⚡ **即時練習模式 (Practice Mode)**：
     - 點選選項立即反饋對錯
     - 即時展開題目詳細觀念解析與考點說明
     - 配合合成音效（答對提示音 / 答錯提示音）
   - 📖 **全卷速讀模式 (Study Guide Mode)**：
     - 一覽全卷 25 題完整題目、選項與觀念深度剖析
     - **即時關鍵字搜尋**（如：搜尋 `SRAM`、`CPU`、`悠遊卡`、`熱插拔` 等）
     - **章節分類篩選**（記憶體架構、電腦五大單元、CPU、儲存媒體、I/O 等）
     - **錯題過濾開關**（一鍵只看在測驗中答錯的題目）

2. **🖼️ 原始考卷照片對照**：
   - 點擊導覽列「原卷照片」按鈕，可直接彈出高解析度燈箱檢視 `15867.jpg`（第 1 頁）與 `15868.jpg`（第 2 頁）。
   - 隨時對照紙本考卷上的字跡、題目與原版排版。

3. **⌨️ 鍵盤快速鍵支援**：
   - `1` / `2` / `3` / `4` 或 `A` / `B` / `C` / `D`：快速選取選項
   - `←`（左方向鍵）：上一題
   - `→`（右方向鍵）：下一題

4. **🎨 質感現代 UI 與完全離線支援**：
   - 🌙 / ☀️ 深色與淺色模式自由切換（支援偏好記憶）
   - 🔊 / 🔇 音效開關（使用 Web Audio API 原生合成音，無需額外音訊檔）
   - 零外部依賴，不需安裝 Node.js 或任何套件，點開即用！

---

## 🚀 如何使用

- **方法 1（最簡單）**：直接雙擊資料夾中的 `啟動網站.bat`。
- **方法 2**：直接在檔案總管雙擊 `index.html`，以 Chrome / Edge / Firefox 等瀏覽器開啟。
